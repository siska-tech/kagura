# 機材一覧

[開発ロードマップ](implementation-roadmap.md)の各段階に必要な機材と、既存記録から確認できる状態。「要確認」は記録がなく、手持ちかどうか不明なもの。型番・本数が決まり次第この表を更新し、試験記録には機材IDを使う。

| ID | 機材・ソフト | 状態 | 使う段階 | 備考 |
|---|---|---|---|---|
| B1 | Tang Nano 9K（シルク3674、GW1NR-LV9QN88PC6/I5、チップID `0x1100481B`） | 確認済み・1台 | 全段階 | [検証状況](validation-status.md) |
| — | 基板内蔵programmer（BL702、FTDI互換として認識） | 確認済み | 全段階 | 注意点は[ビルドガイド](build-and-test.md) |
| — | Windows PC＋WSL Ubuntu | 確認済み | 全段階 | Verilator 5.032、Icarus 10.1（`build/toolchain`）、Gowin Education V1.9.11.03（V1.9.12.04も導入済み・未使用） |
| P | 電源（PC USBポート/USB電源） | 確認済み | M3 | 試験記録には使った電源を書く |

| ID | 機材 | 状態 | 使う段階 | 備考 |
|---|---|---|---|---|
| S1 | HDMI sink: PCモニター | 確認済み・型番未記録 | M3 | 480p/720pで映像・音声を確認済み |
| S2 | HDMI sink: 2台目（別機種） | **未調達** | M3 | 互換性試験の受入条件（2機種以上）に必須 |

| F1 | 外部SPI Flash書込み手段 | 要確認 | 後続拡張 | 基板上のP25Q32U。programmer経由か、FPGA経由の自作書込みか未決定 |

## 計測できないもの

TMDS信号品質、実周波数・ジッタ、消費電流、実機音声のsample完全性は専用計測器がなければ未測定として扱い、機能試験の結果で代替しない。
