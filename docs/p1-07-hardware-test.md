# P1-07 実機互換性試験 / 手順と記録表

実機互換性の受入条件: 2機種以上×2ケーブル、起動20回/抜挿10回/各1時間。全対象で映像と左右音声を確認し、通常運用でerror0。計測器がない項目は未測定と明記し、simulationの証拠と混ぜない。

## 状態（2026-10-23）

**保留**。手持ちのPCモニター1台（S1）で、Flash起動のカラーバー版に問題がないことを確認した。手順ごとの実施回数・ケーブル本数・1時間試験の有無の内訳は未記録。2台目のsinkがないため、受入条件（2機種以上×2ケーブル）は満たしていない。TCL製テレビは不受理のため対象外。sinkが用意できた時点で下表から再開する。

## 判定基準（毎回の観察）

| 記号 | 合格条件 |
|---|---|
| V | カラーバー8本が正しい順・色で表示される |
| B | 白枠が上下左右4辺とも見える（右端は黒バー上の白線） |
| A | 左が高い音、右が低い音で鳴る。途切れ・ノイズなし |
| L | LED: pixel lock・system lock・reset解除の3個が点灯、LED1（mute）・LED2（underflow）・LED3（overflow）が消灯 |

LED2/LED3は一度でも起きるとresetまで点灯を保持する。1時間試験の終了時に消灯していれば、その間のunderflow/overflowは0回。回数は数えられない（counterなし）。

## 手順（組合せS×Cごとに実施）

1. **起動20回**: USBを抜いて5秒以上待ち、挿す。Flashから起動して映像が出るまでの時間とV/B/A/Lを確認する。sinkの電源は入れたまま。
2. **抜挿10回**: 動作中にHDMIケーブルをsink側で抜き、5秒以上待って挿す。映像と音声が戻るかと、V/B/A/Lを確認する。
3. **reset/mute復帰（各組合せ1回以上）**: reset button（pin4）を押している間にLED1（mute）が点灯し、離すと消灯して映像・音声が戻ることを確認する。
4. **1時間連続**: 開始時刻を記録して放置し、1時間後にV/B/A/Lを確認する。途中で画面消失・音切れに気づいたら時刻を記録する。

## 範囲外・未測定

- 入力停止時の無音挿入/復帰は、固定test toneのため実機では起こせない。simulationの証拠は[音声packet統合評価](audio-packet-integration.md)。手順3はreset起因のmute/復帰だけを確認する。
- 周波数・jitter・TMDS電気特性・sinkが受け取ったInfoFrameの内容は計測器なしでは未測定。
- TCL製テレビは公式サンプルでも無信号のため、合格判定の対象機種とは別に原因調査として扱う（[検証状況](validation-status.md)）。
